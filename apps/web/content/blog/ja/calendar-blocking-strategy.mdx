# カレンダーブロッキング戦略：カレンダーを生産性システムに変える

多くの人がカレンダーを1つの用途にしか使っていません。ミーティングの管理です。残りの時間は空白のまま、メール、Slackの通知、「ちょっといいですか」に振り回される受動的な1日になりがちです。

カレンダーブロッキングはこれを逆転させます。1日を成り行きに任せるのではなく、すべての時間の使い方を事前に決める。ミーティング、集中作業、事務処理、休憩 — すべてカレンダーに載せます。空白がなくなり、代わりに意図を持ったブロックがあなたの最も貴重な資源、つまり「注意力」を守ってくれます。

これは[タイムボクシング](/blog/timeboxing-guide)とは厳密には異なりますが、2つは見事に補完し合います。タイムボクシングは特定のタスクに固定時間を割り当てる技法。カレンダーブロッキングは作業カテゴリのために時間を確保する技法です。ブロッキングが建物の構造で、タイムボクシングがインテリアデザインだと考えてください。詳しい比較は[タイムボクシング vs タイムブロッキング](/blog/timeboxing-vs-time-blocking)をどうぞ。

## カレンダーを「計画ツール」として使う

考え方の転換はシンプルですが強力です。カレンダーを「他人に入れられた予定の記録」ではなく、「自分の計画ツール」として扱うこと。

ブロッキングを始めると何が変わるか：

**ミーティングの独占が終わる。** 集中作業にもブロックがあれば、それはもう見えない時間ではありません。同僚にはその時間帯が「予定あり」と表示され、割り込みが減ります。

**時間の行き先が見える。** ミーティングが3つあると「忙しい1日」に感じますが、合計2.5時間なら残り5.5時間あります。ブロックがなければその時間は蒸発します。ブロックがあれば確保されます。

**計画が視覚的になる。** 別アプリにあるToDoリストの代わりに、ミーティングや締切と同じカレンダー上に計画が表示されます。

**基本原則：** 大事なことにはブロックを置く。ブロックがなければ保護された時間がない — 保護されていない時間は真っ先に奪われます。

このアプローチは、ミーティング・メッセージ・コンテキストスイッチで1日が分断される[ナレッジワーカー](/blog/timeboxing-at-work)にとって特に価値があります。カレンダーブロッキングは、オープンエンドなToDoリストでは提供できない構造を生み出します。

## 色分けシステム

色分けは見やすいカレンダーの基盤です。色がなければすべてのブロックが同じに見え、週全体をひと目で把握することができません。

ナレッジワーカーの多くに機能する色分けシステムを紹介します。

| カテゴリ                  | おすすめの色  | 例                                           |
| ------------------------- | ------------- | -------------------------------------------- |
| 集中作業 / ディープワーク | 青            | 執筆、コーディング、デザイン、分析           |
| ミーティング              | 赤 / オレンジ | 1on1、チーム同期、クライアント通話           |
| 事務 / オペレーション     | グレー        | メール、Slack、経費精算、書類整理            |
| 計画 / レビュー           | 緑            | 週次レビュー、デイリープランニング、目標設定 |
| 学習 / 成長               | 紫            | 読書、講座、スキル練習                       |
| 休憩 / プライベート       | 黄            | 昼食、散歩、運動、私用                       |
| ブロック済み / 予約不可   | 濃いグレー    | バッファ時間、移行期間                       |

**色分けのコツ：**

- **5〜7色に抑える。** それ以上はノイズになり、シグナルが消えます。
- **一貫性を保つ。** 青を集中作業にしたら、ずっと青のまま。目指すのは瞬時の認識です。
- **週単位でバランスを見る。** 週表示でカレンダーを開き、色の分布を確認。ほぼ赤（ミーティング）なら問題です。個人貢献者の健全なカレンダーは、おおよそ40-50%が青、20-30%が赤、残りがその他のカテゴリです。

Dayoptではアクティビティの色で予定を見分け、連携したGoogleカレンダーの予定と並べて確認できます。ミーティングが集中時間を圧迫していないか一目でわかり、すぐに対策を打てます。

## 定期ブロックの設定

最もレバレッジの高いブロックは、一度設定したら考えなくて済むもの。つまり定期ブロック — 1週間の骨格です。

**朝の計画ブロック（15〜20分、毎日）。** カレンダーを確認し、ブロックを調整し、今日の意図を設定。ここで[デイリープランニング](/blog/how-to-plan-your-day)を行います。

**メール・メッセージブロック（30分、1日2回）。** メールを1日中チェックする代わりに、2つの時間枠にまとめる。ほとんどの用件は3〜4時間待てます。集中時間が感謝してくれるでしょう。

**週次レビューブロック（30〜45分、金曜日）。** 1週間を振り返る。何ができて、何ができなかったか、来週に持ち越すものは何か。このフィードバックループがカレンダーブロッキングを改善し続けます。

**ディープワークブロック（90〜120分、毎日）。** 最低1つ、中断のない集中ブロックを毎日確保。クリエイティブな仕事や分析的な仕事をする人には譲れない時間です。

**移行 / バッファブロック（15分、主要ブロック間）。** 脳にはギアチェンジの時間が必要です。ストレスの高いミーティングの直後にディープワークを入れないこと。

サンプルの週間スケジュール：

| 時間          | 月曜           | 火曜           | 水曜           | 木曜           | 金曜           |
| ------------- | -------------- | -------------- | -------------- | -------------- | -------------- |
| 8:30 - 8:45   | 計画           | 計画           | 計画           | 計画           | 計画           |
| 9:00 - 10:30  | 集中作業       | 集中作業       | 集中作業       | 集中作業       | 集中作業       |
| 10:30 - 10:45 | バッファ       | バッファ       | バッファ       | バッファ       | バッファ       |
| 10:45 - 11:30 | メール / Slack | ミーティング   | メール / Slack | ミーティング   | メール / Slack |
| 11:30 - 12:00 | 事務処理       | 事務処理       | 事務処理       | 事務処理       | 週次レビュー   |
| 12:00 - 13:00 | 昼食           | 昼食           | 昼食           | 昼食           | 昼食           |
| 13:00 - 14:00 | ミーティング   | 集中作業       | ミーティング   | 集中作業       | 学習           |
| 14:00 - 14:15 | バッファ       | バッファ       | バッファ       | バッファ       | バッファ       |
| 14:15 - 15:30 | 集中作業       | ミーティング   | 集中作業       | ミーティング   | 振り返り       |
| 15:30 - 16:00 | メール / Slack | メール / Slack | メール / Slack | メール / Slack | —              |

これはあくまで出発点であり、厳格なテンプレートではありません。役割、ミーティング量、エネルギーパターンによって変わります。ポイントは、すべての時間に持ち主がいるということです。

パターンに注目してください。エネルギーが最も高い午前中にディープワークを配置。ミーティングは散らばらせずにまとめる。バッファブロックで深い集中と対人コミュニケーションの間のメンタルな切り替えショックを防ぐ。金曜は意図的に軽くして、レビューと学習の時間を確保。

ブロックの最適な長さがわからなければ、上記の時間配分で1週間試してから調整してください。2〜3回の調整で自分に合った長さが見つかるはずです。

## 集中時間を守る

ブロックは守ってこそ機能します。カレンダーの最大の脅威は計画不足ではなく、他の人が空き時間をミーティングで埋めることです。

**戦略1：集中ブロックを見える化する。** ディープワーク用の実際のカレンダーイベントを作成。タイトルは「集中時間 — 予約不可」や単に「予定あり」に。ほとんどのスケジューリングツール（Calendly、Googleカレンダーの予約枠）はこれを尊重します。

**戦略2：ミーティングを特定の時間帯にまとめる。** ミーティングが1日中散らばるのではなく、ミーティング時間帯を決める。例：火曜と木曜の午後。それ以外は辞退か再調整。

**戦略3：ミーティング予算を決める。** 1日や1週間のミーティング時間の上限を決める。上限に達したら受け入れをストップ。どのミーティングに本当に出席が必要かの優先順位付けが強制されます。

**戦略4：「オフィスアワー」パターンを使う。** 突発的な1on1の代わりに、誰でも来られるオープンなオフィスアワーを定期ブロックとして公開。割り込みを予測可能な時間枠に集約します。

**戦略5：朝を守る。** ほとんどの人にとって、午前中はエネルギーが最も高く、創造性が発揮される時間帯。朝を集中作業に充て、ミーティングを午後に回すのは、最もインパクトの大きい変更の1つです。[ディープワークスケジューリング](/blog/deep-work-scheduling)の原則とも一致します。

**集中ブロックにミーティングを入れられたら：** 黙って受け入れないこと。「その時間帯は集中ブロックを入れています。[別の時間]はいかがですか？」と返しましょう。ほとんどの人はミーティングを動かしてくれます。動かさない人は、そのミーティングの本当の緊急度を教えてくれています。

「カレンダーをコントロールできない — 上司がミーティングで埋めてくる」というのはよくある反論です。本当にそうなケースもありますが、多くの場合は思い込みです。1週間のミーティング時間を記録してみてください。自由に使える時間は想像より多いはずです。1日1つでも90分の集中ブロックを取り戻せれば、成果は大きく変わります。

## カレンダーレビューの習慣

カレンダーブロッキングをレビューなしで続けるのは、家計簿をつけても残高を確認しないようなもの。ブロックが現実を反映しているか、定期的にチェックする必要があります。

**デイリーレビュー（2〜3分、1日の終わり）：**

- 今日のブロック通りに過ごせたか？
- どのブロックが中断されたか、時間超過したか？
- 明日のために何を変えるべきか？

**ウィークリーレビュー（20〜30分、金曜日）：**

- 色表示で1週間を見る。集中作業とミーティングの比率は？
- うまく機能している定期ブロックは？無理がある定期ブロックは？
- 先送りやスキップされたものにパターンはあるか？
- 来週の非定期ブロックを設定する。

**マンスリーレビュー（30〜45分）：**

- 全体の構造はまだ自分に合っているか？
- カテゴリや色を更新する必要はあるか？
- 十分な集中時間を確保できているか、ミーティングが再び侵食していないか？
- 今月の[時間の見積もり精度](/blog/how-to-estimate-time-for-tasks)を先月と比較する。

レビューの習慣こそ、カレンダーブロッキングが「一度やって終わり」から「生きたシステム」に進化する場です。レビューがなければ、ブロックはゆっくり劣化し、ミーティングが忍び込み、集中時間が縮小し、1ヶ月で始める前のカレンダーに逆戻りします。

Dayoptのプランとレコードのシステムは、このレビューを具体的なものにします。自分で実績を記録すると、予定と独立した記録を同じ時間軸で比較できます。週次レビューで次の予定を直す材料になります。

## 今週から始めよう

初日からカレンダー全体を再設計する必要はありません。最小限のスタート地点はこちら：

1. **集中作業の色を決める**（青がおすすめ）。今週、毎日1つの90分ディープワークブロックを作成。
2. **毎朝15分の計画ブロック**を追加。
3. **金曜に30分のレビューブロック**を追加して、1週間を振り返る。
4. **メールを1日2回、各30分のブロック**にまとめる。常時チェックをやめる。

変更は4つだけ。追加する前に丸1週間試してください。目標は初日から完璧なカレンダーを作ることではなく、意図的な時間配分の習慣を築くことです。
