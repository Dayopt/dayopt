# Dayoptで実践するタイムボクシング5つのコツ

ToDoリストは「何をするか」を教えてくれます。タイムボクシングは「いつ、どのくらいの時間で」を決めます。タスクをカレンダー上の具体的な時間枠に配置することで、あいまいな意図が明確なコミットメントに変わります。Dayoptでタイムボクシングを実践するための5つのコツをまとめました。

## 1. 最も重要なタスクから配置する

朝9時から順番にカレンダーを埋めていくのはやめましょう。まず今日一番大事なタスクを見つけて、それを最初にタイムボックスに入れます。Dayoptでアクティビティを選んで予定を作り、集中しやすい時間に置きます。具体的な作業内容はメモに残します。[予定の作成と現行ショートカット](/docs/plans)を参照してください。

残りの予定は、このアンカーを中心に組み立てましょう。

## 2. 現実的な所要時間を設定する

ありがちな失敗は、集中作業に4時間のブロックを確保すること。多くの人は60〜90分が深い集中の限界です。

| タスクの種類       | おすすめの時間 |
| ------------------ | -------------- |
| 集中作業           | 60〜90分       |
| ミーティング       | 25分 or 50分   |
| メール・メッセージ | 30分           |
| 軽いタスク         | 15分           |

Dayoptではプランの下端をドラッグしてリサイズできます。実際にかかる時間の感覚が自然と身についていきます。

## 3. バッファ時間を確保する

タイムボックスを隙間なく並べると、燃え尽きとスケジュール崩壊を招きます。ブロック間に15〜30分の余白を残しましょう。移動時間、突発タスク、頭の切り替えに使えます。

Dayoptでは、次の予定を置く前にカレンダーの空いている時間を確認します。すべての隙間を埋めず、活動の間に余白を残しましょう。

## 4. 実際に使った時間を記録する

タイムボクシングの本当の価値は、計画だけでなく **計画と現実の比較** にあります。活動が終わったら、終了済みの予定で **「そのまま記録」** を押します。アクティビティ・時刻・メモをコピーした独立した記録ができます。実際に使った時間が違えば、記録を直します。予定はそのまま残り、片方の編集や削除で相手は変わりません。[記録の作成](/docs/records)を参照してください。

続けていくと、パターンが見えてきます。いつも予定より時間がかかるタスク、生産性が高い時間帯、思ったより時間を使っている活動に気づけるようになります。

## 5. ルーティンの時間を確保する

定期的な活動をいつ行うか決め、その日に予定を置きましょう。

- **平日の朝**: 計画セッション（15分）
- **毎週金曜**: 週次レビュー（30分）
- **毎日**: メール処理（30分）

カレンダーに時間を確保し、活動後は実際に使った時間を自分で記録します。

## はじめの一歩

タイムボクシングに完璧さは必要ありません。まずは1日3〜4個のタイムボックスから始めましょう。習慣が身につけば、自然とカバー範囲が広がります。

大事なのは、**完璧に実行できなくても、計画があるだけで効果的だということ。** 予定通りにいかなかった日も、自分の時間の使い方について何かを学べます。

Dayoptを開いて、最初の予定に使うアクティビティを選びましょう。現在の手順とショートカットは[予定のガイド](/docs/plans)を参照してください。
