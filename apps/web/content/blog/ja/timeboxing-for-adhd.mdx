# ADHDのためのタイムボクシング：本当に使える実践システム

ADHDがあると、これまでにたくさんの生産性システムを試してきたのではないでしょうか。色分けされた手帳、多機能なタスクアプリ、連続記録を売りにした習慣トラッカー。たいていは1週間、よくて2週間で静かにフェードアウトしていきます。

それは自分のせいではありません。デザインの問題です。ほとんどの生産性システムは、定型発達の脳を前提に作られています。持続的なモチベーションや実行機能が一定であることを当然のように想定しているのです。

タイムボクシングは少し違います。魔法だからではなく、ADHDの脳が**実際に動く仕組み**に沿っているからです。なぜそうなのか、そしてどうすれば続く形で始められるのかを見ていきましょう。

## 従来の計画法がADHDに合わない理由

従来の計画法が頼りにしているのは、**外圧なしでの優先順位づけ**、**正確な時間見積もり**、**自発的なタスク切り替え**の3つです。どれもADHDにとってはハードルが高いものばかりです。

ToDoリストには「レポートを書く」と書いてあっても、**いつ**やるか、**どのくらい**かかるかの構造がありません。時間感覚が曖昧なADHDの脳にとって、これは方位磁針なしの地図を渡されるようなものです。行き先はわかっても、距離や方向の感覚がない。

厳密なスケジュールは逆の理由で失敗します。決まった間隔でタスクを切り替えられることが前提になっているからです。でもADHDの脳は予測可能な間隔では動きません。同じタスクでも20分で終わる日もあれば、なぜか先にデスク全体を片づけ始めて2時間かかる日もあります。

結果として、計画を完全に避けるか（どうせ崩れるから）、逆に計画に執着して現実とのズレに打ちのめされるか。どちらも長くは続きません。

## タイムボクシングがADHDの脳に合う理由

タイムボクシングがADHDに向いている理由は、いくつかの具体的なポイントにあります。

**人工的な締め切りを作ってくれる。** ADHDの脳は締め切り駆動型であることが多いです。外からのプレッシャーがなければ、タスクに着手すること自体が困難。タイムボックスは「このタスクに45分、今から」というプレッシャーを生み出します。制約そのものがモチベーションになるのです。

**時間を目に見えるものにしてくれる。** 時間盲（タイムブラインドネス）はADHDの最も厄介な特性の一つです。カレンダー上のタイムボックスは、抽象的な時間を具体的にします。次の予定まで90分あることが**見える**。その視覚的なアンカーが脳の見当識を助けます。

**判断疲れを減らしてくれる。** 座ってカレンダーに「9:00–9:45: ブログ記事の下書き」と書いてあれば、何をするか迷う必要がありません。すでに決まっているからです。判断に膨大なエネルギーを消費する脳にとって、これは大きな救いです。

**やめる許可をくれる。** ADHDの隠れた苦しみの一つは、いつ止めていいかわからないことです。スライドの体裁を整えるのに4時間かけてしまったりする。タイムボックスは「45分で十分。次に行こう」と言ってくれます。その外部からの合図は、本当に解放的です。

| ADHDの課題           | タイムボクシングの効果     |
| -------------------- | -------------------------- |
| 時間感覚の曖昧さ     | カレンダーで時間を視覚化   |
| タスクを始められない | 人工的な締め切りを作る     |
| 判断疲れ             | 何をいつやるか事前に決める |
| タスクを止められない | 明確な終了点を提供する     |
| 時間見積もりが苦手   | 実際の所要時間データを蓄積 |

## 最初のタイムボクシング日の始め方

初日から1日すべてをタイムボックスで埋めようとしないでください。それは挫折への近道です。小さく始めましょう。

**ステップ1: タスクを3つ選ぶ。** 3つだけ。重要だけど緊急ではないタスクを選びます。ADHDの脳が先延ばしにしがちなのは、まさにこのカテゴリです。

**ステップ2: ざっくり見積もる。** 正確さは気にしなくてOK。30分かかりそうなら40分で枠を取る。精度は時間をかけて上がっていきます。

**ステップ3: カレンダーに配置する。** 各タスクを具体的な時間枠に入れましょう。エネルギーレベルに合わせて、朝が冴えているなら一番難しいタスクを朝に。

**ステップ4: タイマーをセットする。** タイムボックスが始まったらタイマーを回す。カウントダウンが体感できるようにします。タイマーが鳴ったら止める。たとえ終わっていなくても。

Dayoptでは、タスクごとにプランを作成してカレンダーの特定の時間枠にドラッグできます。活動が終わったら自分で独立した記録を作り、実際に使った時刻へ直しましょう。数週間続けると、自分の脳がどう動くかのパターンが見えてきます。これはADHDにとって最も価値のある自己理解の一つです。

**現実的な初日の例：**

| 時間  | タスク                  | 長さ |
| ----- | ----------------------- | ---- |
| 9:00  | 最も重要な作業タスク    | 45分 |
| 10:00 | メール・メッセージ      | 30分 |
| 14:00 | 2番目に重要な作業タスク | 40分 |

以上です。タイムボックス3つ。残りの時間はノンストラクチャード。自信がついてきたら少しずつ増やしていきましょう。

## 過集中とタスク切り替えへの対処

過集中（ハイパーフォーカス）はADHDで最も誤解されている特性の一つです。思い通りに呼び出せるスーパーパワーではありません。脳がタスクにロックオンして離さなくなる不随意な状態で、正しい対象に向くこともあれば、まったく見当違いのものに向くこともあります。

タイムボクシングは過集中をなくすことはできませんが、管理するためのフレームワークを提供します。

**過集中が正しいタスクに向いた場合：** 素晴らしい。そのまま走らせましょう。ただし、ハードストップを設けます。タイムボックスが終わったら10分休憩。歩き回る、水を飲む、窓の外を見る。そして判断します：このタスクにもう1つタイムボックスを割くべきか、次に移るべきか。休憩が判断ポイントを作ってくれるのです。過集中のままだと、その判断ポイント自体が消えてしまいます。

**過集中が間違ったタスクに向いた場合：** こちらは難しい。レポートを書くつもりで座ったのに、気づいたらファイリングシステムの再構築に90分費やしていた、というパターン。タイムボックスのタイマーが鳴ったとき、それがライフラインです。タイマーが聞こえたら、起きたことを自分で認識する。ただし自分を責めない。次のタイムボックスに移る。ファイリングシステムはどこにも逃げません。

**タスク切り替えを助ける工夫：**

- **物理的な移動を挟む。** 立ち上がる。別の部屋に行く。水を取りに行く。身体を動かすと、脳が現在のタスクから離れやすくなります。
- **「パーキングロット」メモを書く。** タスクを切り替える前に30秒使って、どこまで進んだか、次に何をするかを書き留める。未完了の不安を減らせます。
- **次のタスクを見える場所に置く。** 次のタイムボックスの内容を目に入る場所に書いておく。タイマーが鳴ったとき、すぐに次が目に入ります。

## バッファ時間と柔軟性

ADHDと計画についての真実を一つ。**スケジュールは崩れます。** 「崩れるかも」ではなく、崩れます。そしてそれは全く問題ありません。

大事なのは、スケジュールが崩れても1日全体が崩壊しないだけの柔軟性を組み込んでおくことです。

**バッファ時間は必須です。** タイムボックスの間に最低15分の未予定時間を入れましょう。これには複数の目的があります。

- タスクが予定より長くかかったときの吸収材になる
- コンテキスト切り替えのための脳の準備時間になる
- 予想外の出来事への余白になる（ADHDでは常に予想外のことが起きます）
- スケジュール遅延のプレッシャーを和らげる

**カレンダーを60%以上埋めない。** 8時間の作業時間があるなら、タイムボックスは5時間分まで。残りはバッファ、突発タスク、呼吸の余白です。「やることが少なすぎる」と感じるかもしれませんが、システムが持続可能になるため、実際にはより多くのことを達成できます。

**タイムボックスが脱線したとき**、午後のスケジュール全体を組み直したい衝動を抑えてください。ただ次のタイムボックスに移りましょう。できなかったタスクは明日の最初のタイムボックスになります。罪悪感なし、再編成なし、ただ前に進む。

Dayoptのカレンダービューなら、バッファ時間がどこにあるか一目でわかります。予定を空いている時間へドラッグすると、時間配分を直せます。

## 役立つツール

タイムボクシングは、ツールが邪魔にならないときに最もうまく機能します。ADHDの脳にとって、ほんの少しの摩擦でもそれが障壁になり得ます。

**タイムボクシングツールに求めるもの：**

- **ビジュアルなカレンダー表示。** 時間をリストではなく**見る**必要があります。色付きブロックのカレンダーが、時間を触れるものにします。
- **素早い入力。** タイムボックスの作成に10秒以上かかると、やらなくなります。キーボードショートカットとドラッグ作成があるものを。
- **柔軟な移動。** ドラッグ&ドロップでのリスケジュールは必須。計画は変わるものだし、ツールはそれを簡単にすべきです。
- **実際に何が起きたかの記録。** 計画時間と実際の時間の比較が、時間をかけて自己理解を深めます。ここに本当の成長があります。

Dayoptはこれらの原則を念頭に設計されています。アクティビティを選んで予定を作成し、適切な時間にドラッグし、端をドラッグして長さを直します。活動後は独立した記録を自分で作ります。[予定の作成と現行ショートカット](/docs/plans)、[記録の作成](/docs/records)を参照してください。時間が経つにつれて、Recordsは自分の時間の使い方のデータベースになります。ADHDのある人にとって、そのデータは宝の山です。

**補助ツール：**

- **物理タイマー**（またはスマホのタイマー）：カウントダウンを体感できる
- **ノイズキャンセリングヘッドホン**：タイムボックス中の気が散る要素を減らす
- **画面横のメモ帳**：タスク切り替え時の「パーキングロット」メモ用

**避けるべきもの：**

- 機能や設定が多すぎるツール（先延ばしの罠になる）
- タイムボックスを逃したことを罰するシステム（罪悪感はモチベーションにならない）
- 毎日セットアップが必要なもの（2週目まで持たない）

## 続けるために

ADHDでタイムボクシングの習慣を築くには忍耐が必要です。助けになるいくつかの原則があります。

**必要だと思うより少なく始める。** 1日2つのタイムボックスで十分な出発点です。量より一貫性。

**完璧ではなく、完了を祝う。** 3つタイムボックスを作って2つ完了したら、それは成功です。それがなければやらなかったかもしれない2つのことをやったのですから。

**振り返りは毎日ではなく、毎週。** 1日の失敗は何も意味しません。1週間の傾向は調整のシグナルです。週に1回Recordsを見て問いかけましょう：何がうまくいった？何がダメだった？何を変える？

**リスタートを前提にする。** システムから離れることがあります。1日かもしれないし、1ヶ月かもしれない。ADHDでは当たり前のことです。システムは戻ってきたときにそこにあります。途切れた連続記録もなければ、背負う罪悪感もありません。カレンダーを開いて、タイムボックスを1つ置くだけです。

ADHDは一人ひとり違いますし、万能なシステムは存在しません。でもタイムボクシングの核心 — 時間に目に見える構造を与えつつ、柔軟性の余地を残す — は、多くのADHDの脳の動き方と驚くほど合っています。試して、適応させて、自分のものにする価値はあります。
