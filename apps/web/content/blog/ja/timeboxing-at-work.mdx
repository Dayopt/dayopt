# 仕事でのタイムボクシング：プロのように1日を管理する

平均的なナレッジワーカーの生産的な時間は、1日あたり約4時間です。残りは会議、Slackメッセージ、メール、コンテキストスイッチ、そしてそれぞれの割り込みからの回復時間に消えています。

これは時間管理の失敗ではありません。現代の仕事のデフォルト状態です。問われているのは割り込まれるかどうかではなく、最も重要な仕事を失わずにそれらの割り込みを吸収できるように1日を設計しているかどうかです。

タイムボクシングは、それを実現する最も効果的な方法です。

## ナレッジワーカーの時間問題

ナレッジワークには構造的な問題があります。**仕事が見えないし、それに費やした時間も見えない。** 工場の作業者は何個の製品を作ったか見えます。ナレッジワーカーは会議とメールで1日を終えて、「今日、実際に何を達成したんだろう？」と疑問に思います。

3つの力が、意味のあるアウトプットなしに1日を埋めてしまいます。

**会議は使える時間を膨張させて埋める。** 30分の会議は本来10分の会話で済んだはずで、それはメールで済んだはずで、それはSlackメッセージで済んだはず。でもカレンダーに入った瞬間、その時間枠を所有します。さらにその前10分（意味のある作業を始められない）と後15分（頭がまだ会議の中にいる）も奪われます。

**受動的な仕事が能動的な仕事を駆逐する。** メールやメッセージへの返信は生産的に感じます。実際に生産的です。ただし、それは他人の優先事項であってあなたの優先事項ではありません。意図的な構造がなければ、受動的な仕事が1日をすべて埋め、自分のプロジェクトは永遠に始まりません。

**コンテキストスイッチは見えないのに代償が大きい。** 研究によると、割り込みの後に完全に集中を取り戻すまで平均23分かかります。午前中に4回割り込まれたら、1時間半以上が失われます。割り込み自体の時間を含めずに。

タイムボクシングは、時間配分を見えるもの・意図的なものにすることで、3つの問題すべてに対処します。

## タイムボックスで1日を構成する

タイムボクシングされた1日には3種類のブロックがあります。**集中ブロック**、**対応ブロック**、**バッファブロック**です。

**集中ブロック**は最も重要な仕事のため。あなたにしかできない思考、創造、問題解決のための保護された時間枠です。推奨時間：60〜90分。

**対応ブロック**はメール、メッセージ、簡単な依頼のため。受動的な仕事を特定の時間枠にまとめることで、1日中にじみ出るのを防ぎます。推奨時間：30〜45分。

**バッファブロック**は他のブロックの間の未予定の隙間。長引く会議、予想以上に時間がかかるタスク、上司からの突然の依頼を吸収します。

**タイムボクシングされた1日の例：**

| 時間        | ブロック種別    | 内容                                   |
| ----------- | --------------- | -------------------------------------- |
| 8:30–9:00   | 対応            | メール確認、Slackキャッチアップ        |
| 9:00–10:30  | 集中            | 最重要プロジェクトの作業               |
| 10:30–10:45 | バッファ        | 切り替え、コーヒー、小タスク           |
| 10:45–11:30 | 会議            | チームスタンドアップ＋プロジェクト同期 |
| 11:30–12:00 | 対応            | メッセージ返信、レビュー依頼対応       |
| 12:00–13:00 | —               | 昼休み                                 |
| 13:00–14:30 | 集中            | 2番目に重要なプロジェクト作業          |
| 14:30–14:45 | バッファ        | 切り替え                               |
| 14:45–15:30 | 会議            | 1on1または定例ミーティング             |
| 15:30–16:00 | 対応            | メール、Slack、事務作業                |
| 16:00–16:30 | バッファ/まとめ | 明日の計画、残件整理                   |

重要なポイントは、**集中ブロックを先に配置し、会議をその周りにはめ込む**ことです。ほとんどの人はこれを逆にやっています。会議にスケジュールを支配させ、集中作業を隙間に押し込もうとする。それではほぼうまくいきません。

Dayoptでは、集中ブロックのアクティビティを選び、具体的な作業内容をメモに残します。アクティビティの色で作業の種類を見分けられます。活動後は実際に使った時間を独立した記録として残します。[予定の作成](/docs/plans)と[記録の作成](/docs/records)を参照してください。

## 会議と割り込みへの対処

会議はタイムボクシングされた1日にとって最大の脅威です。対処法を見ていきましょう。

**会議をまとめる。** 可能なら、会議を1日の中の一つの時間帯にまとめましょう。午前中に3つの連続会議＋午後フリーのほうが、3つの会議が1日中に散らばっているよりずっと良い。散らばった会議は、その前後の集中ブロックも破壊するからです。

**デフォルトを短くする。** ミーティングのデフォルト時間を30分から25分に、60分から50分に変更しましょう。会議間のバッファが生まれ、時間を大切にしている姿勢を示せます。

**毎日最低1つの集中ブロックを守る。** カレンダーに90分の「集中タイム」を入れて「予定不可」にする。本当に緊急でない限り、その時間と衝突する会議は断る。ここが最も重要な仕事をする場所です。

**割り込みは「あとで」リストで対処。** 集中ブロック中に誰かが話しかけてきたり、緊急メッセージが来たら、書き留めて次の対応ブロックで返信する。ほとんどの「緊急」は60分待てます。

| 割り込みの種類     | 集中ブロック中の対応                                         |
| ------------------ | ------------------------------------------------------------ |
| Slackメッセージ    | 通知をスヌーズ、次の対応ブロックで返信                       |
| メール             | 対応ブロックまで無視                                         |
| デスクに来る同僚   | 「[時間]まで集中ブロック中。その後そちらに行っていい？」     |
| 上司からの依頼     | 緊急度を評価：本当に急ぐなら対応、そうでなければスケジュール |
| 「ちょっといい？」 | メモして、バッファか対応ブロックで対応                       |

**断ることについて一言。** 集中時間を守ることは利己的ではありません。チームと組織が本当に必要としている深い仕事を生み出す唯一の方法です。ほとんどの人は、境界線を理解すれば尊重してくれます。

## チーム全体でのタイムボクシング

タイムボクシングはチーム全体で導入すると、さらに効果を発揮します。その理由は、仕事での最大の割り込み源は自分の同僚だからです。全員のスケジュールがブラックボックスだと、情報を得る他の手段がないため、常に互いに割り込み合います。

**チームタイムボクシングの導入方法：**

**ステップ1：共有の集中時間を設ける。** チームとして特定の時間帯を会議禁止にする合意をします。例えば、毎日9:00〜11:00は「メイカータイム」。会議なし、チャットなし。全員がこの枠は聖域だと知っている。

**ステップ2：スケジュールを見えるようにする。** チームメンバーが互いのタイムボクシングされたカレンダーを見られると、自然と集中ブロック中の割り込みを避け、質問を対応ウィンドウにまとめるようになります。この共有にはチームのカレンダーを使い、Dayoptには個人の予定と記録を残します。

**ステップ3：会議を容赦なくタイムボックスする。** すべての定例会議にタイムボックスと明確なアジェンダを設定。スタンドアップが15分なら15分で終了。話し足りないことがあれば、フォローアップや非同期チャネルに移す。

**ステップ4：非同期をデフォルトにする。** リアルタイムの議論が不要な質問には非同期チャネル（Slackスレッド、共有ドキュメント、録画）を使う。同期ミーティングは意思決定、ブレインストーミング、関係構築に限定する。

**チームがタイムボクシング導入後に実感する効果：**

- 会議が減る（非同期がカバーする範囲が増えるため）
- 会議が短くなる（アジェンダ付きのタイムボックスがあるため）
- 集中時間が増える（共有の集中時間が守られるため）
- ワークライフバランスが改善する（1日の境界が明確になるため）
- アウトプットの質が上がる（深い仕事が実際に行われるため）

## リモート vs オフィスでの違い

タイムボクシングはリモートでもオフィスでも機能しますが、課題は異なります。

**リモートワークの課題：**

リモートワーカーが苦労しがちなのは**境界線のぼやけ**です。物理的な通勤やオフィスの閉館時間がないと、仕事がすべての時間を浸食します。タイムボクシングは人工的な境界を作ります。「17:30で仕事を終える」がカレンダー上で見えるとき、それは実感を伴います。

リモートワーカーはオフィスワーカーよりも**会議が多い**傾向もあります。廊下ですれ違いに交わす会話が、スケジュールされた通話に変わるからです。会議を非同期に転換することに積極的になりましょう。リアルタイムの議論が不要なら、会議にすべきではありません。

**リモートでのタイムボクシングのコツ：**

- 1日の始めと終わりに「通勤」タイムボックスを作る（15分の散歩、運動、読書）。切り替えのシグナルになります
- 集中ブロック中は「取り込み中」ステータスを使う
- 集中時間中はコミュニケーションアプリを完全に閉じる。ミュートではなく、閉じる
- 昼休みをタイムボックスにして、実際にデスクを離れる

**オフィスワークの課題：**

オフィスワーカーは**物理的な割り込み**に対処しなければなりません。デスクに来る人、聞こえてくる会話、突発的なミーティング。デジタルの割り込みより管理が難しいです。

**オフィスでのタイムボクシングのコツ：**

- 集中ブロック中はヘッドホンを着ける（音楽なしでもOK。視覚的なシグナルになる）
- 最も重要な集中ブロックには静かな部屋や別のスペースを見つける
- タイムボクシングしたカレンダーを身近な同僚と共有して、いつ話しかけていいかわかるようにする
- 物理的なインジケーター（デスクのサイン、特定の作業場所）で集中中であることを示す

**どちらの環境でも有効なこと：**

- 朝、タイムボクシングした計画を確認して1日を始める
- 夕方、実際に何が起きたかを記録して明日の計画を立てて1日を終える
- 対応ブロックの時間を一定にして、同僚がいつ連絡できるかわかるようにする
- 毎日最低2時間の中断されない集中時間を守る

Dayoptはリモートでもオフィスでも同様に活用できます。カレンダービューが作業場所に関わらず1日の明確な全体像を提供し、Recordsが自分の作業環境が集中時間を支えているか損なっているかの追跡を助けてくれます。

タイムボクシングの基本的な概要は[タイムボクシングガイド](/blog/timeboxing-guide)をどうぞ。タイムボクシングとタイムブロッキングの違いが気になる方は[タイムボクシング vs タイムブロッキング](/blog/timeboxing-vs-time-blocking)で解説しています。現在の時間の使い方を見直すなら[タイムオーディットの方法](/blog/time-audit-how-to)を、日次プランニングの手法には[デイリープランニングメソッド](/blog/daily-planning-methods)をご参照ください。
