# Create Plans

Plans are the core of timeboxing in Dayopt. A Plan is something you intend to do — a meeting, a focused work session, an errand. You put it on the calendar first, so you can see how your day is spent.

## Creating a Plan

There are four ways to create a Plan.

| Method                    | How                                                       |
| ------------------------- | --------------------------------------------------------- |
| **Click on the calendar** | Click an empty time slot                                  |
| **Drag on the calendar**  | Drag across a time range to set the start and end time    |
| **`C`**                   | Create a timeblock                                        |
| **`Shift+C`**             | Create a 15-minute timeblock starting at the current time |

The Inspector opens when the Plan is created. Type a title and it saves as you go.

## Editing a Plan

Click a Plan on the calendar to open the **Inspector**. You can edit these fields:

- **Title** — saves automatically as you type
- **Date** — move the Plan to a different date
- **Time** — adjust the start and end (duration is shown automatically)
- **Activity** — one activity per timeblock
- **Note** — write down what the Plan is about

Inside the Inspector, use `↑` / `k` and `↓` / `j` to move between timeblocks. Press `Escape` to close it.

## Check recent actuals before setting the length

Pick an activity and a line appears directly above the date and time fields — "Recent actuals for this activity are around 45m". It lets you see how long this thing usually takes before you commit to a time.

The figure is your recorded time over the last four weeks divided by your ended planned time over the same period, applied to the length you are currently drafting, and rounded to 5 minutes.

- It only appears while the end time is in the future. Move the end into the past and the Plan becomes a Record, so the line disappears
- If the activity has fewer than three ended Plans in the last four weeks, nothing is shown

## Drag and Drop

- **Move** — drag a Plan to a different time slot
- **Resize** — drag the bottom edge to change the end time

Press `Escape` during a drag to cancel.

## Adding an Activity to a Plan

Each Plan takes one activity. Sort your time by how you spend it — "Deep work", "Meeting", "Admin" — and you can see where the hours went when you review.

A timeblock holds one activity. You cannot add more than one.

## Recording time from a Plan

Use **"Record as-is"** to copy an ended Plan's activity, times, and note into a new, independent Record. The Plan stays unchanged. Moving or deleting either one leaves the other alone.

The Plan Inspector lists **"Records during this time"** for the same activity with at least 15 minutes of overlap. This is time context, not a completion status. If you move a Record away and its old time becomes free, you can copy the Plan again.

## Duplicating a Plan

Open the Inspector menu and select **"Duplicate"** to create another Plan with the same details. You can also copy the Plan and paste it at another time.

## Using the sidebar

The sidebar is where you switch views (day, several days, week), filter which categories and activities are shown, and manage your templates.

## Keyboard Shortcuts

| Shortcut          | Action                                 |
| ----------------- | -------------------------------------- |
| `C`               | Create a timeblock                     |
| `Shift+C`         | Create a timeblock at the current time |
| `Escape`          | Close the Inspector / cancel a drag    |
| `↑` or `k`        | Previous timeblock                     |
| `↓` or `j`        | Next timeblock                         |
| `Cmd+C` / `Cmd+V` | Copy / paste                           |
| `Delete`          | Delete the selected timeblock          |

On Windows and Linux, use `Ctrl` instead of `Cmd`. Press `Shift+?` to see the full list.
