# What is Dayopt?

Dayopt is a **time management and self-awareness tool** for individuals. It does three things in one place:

1. **Plan** — schedule your work as time blocks
2. **Track** — record how you actually spent the time
3. **Reflect** — look at the gap between the two

Most task managers focus on what you need to do. Dayopt focuses on **when and how long**, so you build a realistic sense of your own time.

## Core concept: timeboxing

Timeboxing means giving each task a fixed block of time before you start. Instead of an open-ended list, you decide:

- **What** to work on
- **When** to start
- **How long** to spend

Dayopt puts your calendar and your intentions in the same view, so this is easy to practice.

## How Dayopt works

### 1. Create plans

A plan is something you intend to do. It has a title, a start time, an end time, and one activity.

- Drag on the calendar to create a plan
- Sort your time with activities. Group them into categories for color and icon coding

### 2. Record actual time

A record is the time you actually spent. Create one after the fact, or from a plan you finished.

- Create records on their own, or copy the time and activity from a finished plan
- Plans and records remain independent; comparisons are calculated from their time and activity

### 3. Review

The Review page shows patterns in how you spend time.

- Tracked time and your most-used activity
- Time by activity, and where plan and record diverged
- Estimation accuracy per activity
- Records by day of week and by hour
- Blank time — the hours with no name on them

## Key features at a glance

| Feature                | Description                                                           |
| ---------------------- | --------------------------------------------------------------------- |
| **Calendar**           | 1-day, 2–7 day, and week views with drag-and-drop                     |
| **Plans**              | Timeboxed intentions you place on the calendar                        |
| **Records**            | The time you actually spent                                           |
| **Activities**         | Grouped into categories with colors and icons, one activity per block |
| **Review**             | Time by activity, plan-vs-record, and rhythm by day and hour          |
| **Search**             | Find a block by title with `Cmd+K`                                    |
| **Keyboard shortcuts** | Create and navigate without leaving the keyboard                      |

## Who is Dayopt for?

Dayopt is built for **individuals** who want to:

- Understand where their time goes
- Build better daily routines
- Practice intentional time management
- Track their time without running a project management tool
