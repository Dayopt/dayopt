# Connect AI assistants with MCP

You can let AI assistants like Claude and ChatGPT read your Dayopt data. Once connected, you can ask things like "Look at my records this week and suggest a plan for next week" — and the answer is based on how you actually spent your time. MCP access is a Pro plan feature.

## What is MCP?

MCP (Model Context Protocol) is a shared standard that connects AI assistants to outside apps. Dayopt runs an MCP server. Add one URL to your AI assistant, and it can securely access the data in your account.

## What AI assistants can read

A connected AI assistant can read the following data.

| Data        | What it includes                                          |
| ----------- | --------------------------------------------------------- |
| Plans       | Your upcoming time, as a list or in detail                |
| Records     | Time you actually spent, as a list or in detail           |
| Activities  | The activities and categories you use to group blocks     |
| Review      | Stats such as how plans compare to records                |
| Constraints | Time slots already taken, and the rules for placing plans |

**Connections are read-only for now.** AI assistants cannot create, change, or delete your plans and records. Write access is in a closed beta.

## How to connect

The flow is the same for every client.

1. Open Dayopt Settings, go to "Data Controls", and copy the MCP Server URL in "MCP / API"
2. Add the URL to your AI assistant's settings
3. A Dayopt sign-in and consent screen opens. Check the details and approve

If you are not on the Pro plan, the "MCP / API" section shows an upgrade notice instead.

### Claude

1. Open Settings in claude.ai or the Claude app
2. Under Connectors, choose "Add custom connector"
3. Enter a name (for example, Dayopt) and the copied URL, then add it
4. Approve on the Dayopt consent screen that opens when you connect

### ChatGPT

1. Open Connectors in ChatGPT Settings (some setups require turning on developer mode first)
2. Add the copied URL as a new connector
3. Approve on the Dayopt consent screen that opens when you connect

### Cursor

1. Open the MCP settings in Cursor Settings
2. Add the copied URL as a new MCP server. If you edit the config file, use this format

```json
{
  "mcpServers": {
    "dayopt": {
      "url": "https://mcp.dayopt.app"
    }
  }
}
```

3. Follow the sign-in prompt in Cursor and approve on the Dayopt consent screen

## If the connection fails

| Problem                                    | What to check                                                             |
| ------------------------------------------ | ------------------------------------------------------------------------- |
| No MCP Server URL appears in Settings      | Check that you are on the Pro plan. The free plan cannot connect          |
| The client fails to connect                | Copy the URL from Settings again and check for extra characters around it |
| The consent screen shows an error          | Sign in to Dayopt in the same browser, then try connecting again          |
| Nothing works after approving              | Remove the connection on the client side and start over                   |
| Activities or review data are not readable | If you connected before, reconnect to refresh what the assistant can read |

If the problem continues, [contact us](/contact) and our support team will help.
