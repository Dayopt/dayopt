# 記録をつける

記録は「実際に使った時間」の事実です。これからやるつもりの時間である「予定」とは別の存在で、カレンダー上でも予定と記録は左右のレーンに分かれて並びます。何かが自動で記録になることはありません。記録するかどうかは常にあなたが決めます。

## 記録の独立性

記録は、予定からコピーして作っても、直接新しく作っても独立しています。記録を編集・移動・削除しても、元の予定が変わることはありません。

## 予定から記録を作る

予定の時間が過ぎても、自動的に記録には変わりません。次のいずれかの操作をするまで「未記録の予定」のまま残ります。

| 方法                     | 操作                                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| **「そのまま記録」**     | 予定をクリックして「そのまま記録」を押すと、予定と同じ時間帯・アクティビティの記録が作成されます         |
| **記録レーンへドラッグ** | 予定を記録レーンへドラッグします。実際に使った時間がずれている場合は、端をドラッグして長さを変更できます |
| **「この日を確定」**     | その日の終了済み予定のうち、記録と重なっていない予定をまとめて記録へコピーします                         |

## 記録を直接作成する

予定を立てていなかった時間でも、直接記録を作成できます。カレンダー上で、すでに終了した過去の時間帯をクリックまたはドラッグすると、Dayopt は自動的に記録として作成します。「予定として保存するか記録として保存するか」を選ぶ必要はありません。終了時刻が現在より未来なら予定、現在時刻以前なら記録として保存されます。

## 予定と記録を比較する

カレンダー上では、時間が重なる予定と記録が左右に並んで表示されます。振り返りページでは、予定に対して記録がどう動いたか、どのアクティビティにどれだけ時間を使ったかを確認できます。

過去の予定も、時間・タイトル・アクティビティ・メモを後から自由に編集できます。編集しても予定のままで、記録へ勝手に変わることはありません。

## 記録を編集する

記録をクリックすると Inspector（詳細パネル）が開き、以下を編集できます。

- **タイトル・アクティビティ・メモ** — 予定と同じ項目
- **開始・終了時刻** — 記録はすでに起きたことの事実なので、いつでも修正できます（終了時刻を未来に設定することはできません）
