# よくある質問

Dayoptへの質問を7つのページに分けています。

- **[機能](/docs/faq/features)** — タイムボクシングの考え方、予定と記録の違い、アクティビティ、振り返りで見られること、キーボードショートカット、オフライン対応
- **[競合との違い](/docs/faq/comparison)** — Googleカレンダー、Todoist、Toggl、ポモドーロアプリ、手帳との使い分け
- **[プライバシーとセキュリティ](/docs/faq/privacy-security)** — データの暗号化、第三者への提供、アカウント削除、Cookieと計測の扱い
- **[料金](/docs/faq/pricing)** — 単一プランの内容、45日間の無料体験、支払い、解約、返金
- **[技術](/docs/faq/technical)** — 対応ブラウザ、PWA、API、アクセシビリティ、多言語対応
- **[考え方](/docs/faq/philosophy)** — Dayoptが何を大事にしているか。機能を増やさない理由
- **[その他](/docs/faq/general)** — 開発体制、フィードバックの送り先、サポート、名前の由来
