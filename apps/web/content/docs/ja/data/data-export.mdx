# データを書き出す

Dayoptに記録したデータを、CSVまたはJSONファイルとして書き出せます。無料体験や契約が終了した後も利用できます。

## エクスポートの手順

1. **設定 > データ** を開く
2. 「エクスポート」で形式と範囲を選ぶ
3. **「エクスポート」** ボタンを押すとファイルがダウンロードされる

範囲は「全期間」と「期間指定」から選べます。期間指定では開始日と終了日を指定します。

## 形式の違い

| 形式     | 用途                 |
| -------- | -------------------- |
| **JSON** | バックアップ・復元用 |
| **CSV**  | 表計算ソフトで開く用 |

## 含まれるデータ

エクスポートには次のデータが含まれます。

- プロフィール情報
- タイムブロック（予定と記録）
- アクティビティ設定
- カレンダー設定
- その他の設定
