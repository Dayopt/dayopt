# MCP で Claude または ChatGPT を Dayopt に接続する

MCP（Model Context Protocol）を使って、AI アシスタントを Dayopt アカウントに接続できます。接続には OAuth を使います。Dayopt の許可画面に表示される権限を確認してから承認してください。

MCP 接続には Dayopt アカウントが必要です。使える権限はクライアントと、Dayopt がそのアカウントとクライアントに書き込みベータを許可しているかによって異なります。

## 読み取れるデータ

許可されたクライアントは、付与された権限の範囲で Dayopt のデータを読み取れます。

| データ         | 内容                                                 |
| -------------- | ---------------------------------------------------- |
| 予定           | これから行う時間の一覧と詳細                         |
| 記録           | 実際に使った時間の一覧と詳細                         |
| アクティビティ | タイムブロックの分類に使うアクティビティとカテゴリー |
| セグメント     | 時間を分析するための保存済みクエリ                   |
| 振り返り       | 予定と記録の比較などの統計                           |
| 制約           | 予定を置く時のルールと、すでに埋まっている時間帯     |

## 読み取りと書き込みの権限

ChatGPT Pro のカスタム MCP アプリは、Developer Mode で読み取りと取得の権限を使えます。MCP 経由の書き込みはできません。利用可能なプランと設定方法は、[OpenAI の ChatGPT MCP ガイド](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt)で確認してください。

Dayopt の書き込み機能は限定ベータです。書き込みには、Dayopt アカウントと対象の MCP クライアントが有効で、アカウントが現在の利用条件を満たしている必要があります。有効でないクライアントには読み取り専用の権限が付与されます。

許可画面に、この接続で使える権限が表示されます。`write:plans` は予定の作成と更新を許可します。`write:records` は記録の作成と更新を許可します。`delete:plans` と `delete:records` は、それぞれ対象の予定や記録をゴミ箱へ移動し、復元する権限です。承認前に権限を確認してください。

書き込み権限を許可すると、クライアントが書き込み操作を実行した時に対象データが直接変更されます。許可画面は、変更のたびに確認を求めるものではありません。クライアント側で、実行前に書き込み内容を確認できるか調べてください。内容を確認できない場合は、読み取り専用の接続を使ってください。

## MCP サーバー URL を確認する

1. Dayopt の設定を開き、**データ管理**へ進みます。
2. **MCP / API** に表示される URL をコピーします。
3. AI アシスタント側に URL を登録し、Dayopt の許可画面に表示された権限を承認します。

## Claude を接続する

1. Claude で **Customize → Connectors** を開きます。
2. **+ → Add custom connector** を選び、名前に `Dayopt`、URL に Dayopt でコピーした URL を入力します。
3. **Advanced settings** で OAuth Client ID に `claude-ai` を入力し、OAuth Client Secret は空欄にします。
4. **Add** を選び、Dayopt に接続してから、表示された権限を確認して承認します。
5. 会話画面で **+ → Connectors** を開き、Dayopt を有効にします。

Claude への書き込み権限は、Claude クライアントと Dayopt アカウントが書き込みベータの対象になっている場合に限り付与されます。それ以外は読み取り専用です。最新の画面手順は[Anthropic のリモート MCP 接続ガイド](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)を確認してください。

## ChatGPT Pro を接続する

ChatGPT の Web 版を使います。ChatGPT Pro のカスタム MCP アプリは、現在、読み取りと取得の権限のみを利用できます。

1. ChatGPT の Web 版で、設定から **Developer Mode** を有効にします。項目が見つからない場合は、利用プランに対応した OpenAI の最新ガイドを確認してください。
2. **Settings → Apps → Create** を開き、Dayopt のカスタムアプリを作成します。
3. Dayopt でコピーした URL を入力し、ツールを読み込んでから OAuth 接続を完了します。
4. Dayopt にサインインし、許可画面に表示された読み取り権限を承認します。
5. 新しい会話でツールメニューから Dayopt アプリを選びます。

Dayopt のツール一覧を変更した後に呼び出しに失敗する場合は、カスタムアプリの設定を開いてツールを再読み込みします。必要に応じてアプリを作り直してください。手順は[OpenAI の最新セットアップガイド](https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt)で確認できます。

## 読み取りから予定・記録・振り返りを試す

会話で Dayopt を選び、予定と記録を別々に読み取ります。

> [タイムゾーン]で[日付]の開始から翌日の開始までを指定し、予定と記録を別々に一覧にしてください。予定と実際に使った時間を分けてください。

許可画面に `write:plans` が表示された場合は、まず書き込みツールを呼ばずに下書きを作るよう頼みます。

> [アクティビティ]の[タイトル]という予定の下書きを、[開始時刻]から[終了時刻]までで作ってください。UTCオフセットを含むISO 8601形式で日時を指定してください。まだDayoptの書き込みツールは呼び出さないでください。タイトル、アクティビティ、開始時刻、終了時刻を表示してください。

下書きを確認した後、別の指示で予定の作成を依頼します。クライアントが `plans.create` を呼び出した時に変更が反映されます。Dayopt のカレンダーに予定が表示されたことを確認してください。

許可画面に `write:records` が表示され、実際に活動した後であれば、記録も同じ2段階で作成できます。

> [アクティビティ]の[タイトル]という記録の下書きを、[過去の開始時刻]から[過去の終了時刻]までで作ってください。UTCオフセットを含むISO 8601形式で日時を指定してください。まだDayoptの書き込みツールは呼び出さないでください。タイトル、アクティビティ、開始時刻、終了時刻を表示してください。

下書きを確認した後、別の指示で記録の作成を依頼します。クライアントが `records.create` を呼び出した時に変更が反映されます。記録の終了時刻は現在時刻以前である必要があります。拒否動作を確かめるには、終了時刻が未来の記録を依頼し、Dayopt が拒否して記録が作られないことを確認してください。未来の時間には予定を作ってください。たとえば `2026-10-05T09:00:00+09:00` は、UTCオフセットを含むISO 8601形式の日時です。

予定と記録を別々に読む `plans.list` と `records.list` には `read:entries` 権限が必要です。アクティビティを選ぶために一覧を読む場合は `activities.list` と `read:activities` 権限を使います。`review.get` は予定と記録を最大31日の期間で比較し、`read:stats` 権限が必要です。まとめて一覧にする場合は `entries.list` も使えます。

ChatGPT Pro は読み取りと取得のみ対応しているため、上の書き込み手順は使えません。クライアントに書き込み権限が表示されない場合は、読み取りだけを使い、許可画面に表示された権限を確認してください。

## 接続を取り消す、または再接続する

Dayopt へのアクセスを取り消すには、Dayopt の **設定 → 連携 → MCP 接続**を開き、対象クライアントのアクセスを取り消します。クライアント側からコネクタを削除することもできます。クライアント側の削除だけでは、Dayopt 側のアクセス取り消しの代わりになりません。

再接続するには、クライアントから接続し直して Dayopt にサインインします。許可画面に表示された現在の権限を確認してから承認してください。

## 接続できない時

| 症状                                         | 確認すること                                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 設定に MCP サーバー URL が表示されない       | Dayopt にサインインして **設定 → データ管理**を開きます。表示されない場合はお問い合わせください。 |
| ChatGPT Pro で予定や記録を作成・変更できない | ChatGPT Pro のカスタム MCP アプリは、現在読み取りと取得のみです。                                 |
| クライアントが接続できない                   | Dayopt の設定から URL をコピーし直し、前後に余分な文字がないか確認します。                        |
| 許可画面でエラーになる                       | 同じブラウザで Dayopt にサインインしてから、もう一度試します。                                    |
| ChatGPT が redirect URI のエラーを表示する   | 接続を中断し、エラー文を添えて Dayopt にお問い合わせください。                                    |
| サーバー変更後もツールを使えない             | 再接続して現在の権限を承認します。ChatGPT ではアプリ設定からツールを再読み込みします。            |
| 取り消した接続を再び使いたい                 | クライアントから接続し直し、新しい接続を承認します。                                              |

解決しない場合は[お問い合わせ](/contact)ください。
