# Dayoptとは

Dayoptは、個人向けの**時間管理と自己理解のツール**です。3つのことを1つの画面で行います。

1. **計画する** — やることを時間ブロックとして置く
2. **記録する** — 実際に使った時間を残す
3. **振り返る** — 予定と記録の差を見る

多くのタスク管理ツールは「何をやるか」を扱います。Dayoptが扱うのは「いつ、どのくらい」です。自分の見積もりが、使ううちに現実に近づきます。

## 中心にある考えかた: タイムボクシング

タイムボクシングは、やることに時間の枠を先に決めるやりかたです。終わりのないリストの代わりに、次の3つを決めます。

- **何を**やるか
- **いつ**始めるか
- **どのくらい**かけるか

Dayoptはカレンダーと予定を同じ画面に置きます。この習慣を続けやすくするためです。

## Dayoptの使いかた

### 1. 予定を立てる

予定は、これからやることです。タイトル、開始時刻、終了時刻、アクティビティを1つ持ちます。

- カレンダーをドラッグして予定を作る
- アクティビティで時間の使い道を分ける。カテゴリーにまとめると、色とアイコンで見分けられる

### 2. 実際の時間を記録する

記録は、実際に使った時間です。あとから作ることも、終えた予定から作ることもできます。

- 記録は単独でも、終えた予定の時間とアクティビティをコピーして作れる
- 予定と記録は独立したまま、時間とアクティビティから比較される

### 3. 振り返る

振り返りページで、時間の使いかたの傾向が見えます。

- 記録された時間と、最も多いアクティビティ
- アクティビティ別の時間と、予定と実績がずれたアクティビティ
- アクティビティ別の見積もり精度
- 曜日別・時間帯別の記録
- 空白の時間（名前が付いていない時間）

## 主な機能

| 機能                         | 内容                                                       |
| ---------------------------- | ---------------------------------------------------------- |
| **カレンダー**               | 1日 / 2〜7日 / 週の表示とドラッグ&ドロップ                 |
| **予定**                     | カレンダーに置く、これからやることの宣言                   |
| **記録**                     | 実際に使った時間                                           |
| **アクティビティ**           | カテゴリーでまとめて色分け。1ブロックに1アクティビティ     |
| **振り返り**                 | アクティビティ別の時間、予定と実績の差、曜日・時間帯の傾向 |
| **検索**                     | `Cmd+K` でタイトルからブロックを探す                       |
| **キーボードショートカット** | キーボードだけで作成と移動ができる                         |

## こんな人に向いています

Dayoptは、次のようなことをしたい**個人**のために作っています。

- 時間がどこに使われているかを知りたい
- 毎日の習慣を整えたい
- 意識して時間を使いたい
- プロジェクト管理ツールを持ち出さずに時間を記録したい
