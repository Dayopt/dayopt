# 振り返りを読む

振り返りは、予定と記録の距離を静かに示す読み物です。ダッシュボードではありません。点数もstreakも付けず、比べる相手は自分の過去の記録だけです。

## 開いて期間を選ぶ

レポートは `/report` の独立したページです。表示できる期間は週・月・年の3つで、ヘッダーで切り替えます。`‹` `›` で前後の期間へ移動します。

期間はカレンダーの表示範囲とは別に持ちます。カレンダーで3日表示にしていても、レポートは週のままです。週の始まりは設定の「週の開始曜日」に従います。

モバイルでは粒度の切り替えボタンを出さず、左右のスワイプで前後の期間へ動きます。デスクトップで月を見て共有したリンクは、スマホで開いても月のままです。

## 3つのタブで読む

タブは目的で固定しています。並べ替えや追加、ウィジェットの設定はありません。期間の切り替えとは独立した軸です。

| タブ             | 読むもの                 |
| ---------------- | ------------------------ |
| **時間の使い方** | 何にいくら使ったか       |
| **差分**         | 予定と記録はどう違ったか |
| **振り返り**     | それは良い使い方だったか |

タブを切り替えても集計はやり直しません。描く面が変わるだけです。

### 時間の使い方

その期間の事実だけを並べます。

- **数字のカード3枚** — 記録時間、記録の件数、1件あたりの中央値。それぞれ前の期間との差を添えます
- **日ごとの記録時間** — 期間の中でどの日に厚みがあったか
- **配分** — 記録時間の合計を100%とした横棒。記録のあるカテゴリーが2つ以上ならカテゴリー別、1つならその中のアクティビティ別に分けます
- **アクティビティ一覧** — 記録のある行を全部出します。記録時間の多い順と、前の期間との差の順を切り替えられます
- **時間帯の分布** — 0時から23時まで、1時間ごとの記録時間
- **1件の長さの分布** — 1件がどれくらいの長さになりがちか

前の期間との差は、いま見えているアクティビティだけで足します。前の期間に記録が1分も無ければ、差は出しません。増減は矢印と符号だけで示し、良し悪しの色は付けません。

### 差分

アクティビティごとに、記録の棒と予定の棒（破線）を並べます。隣に予定比を添えます。

**見積もりの鏡** には、見積もりの癖が強いアクティビティを最大3件出します。候補になるのは「終了済みの予定が30分以上」「記録がある」「終了済みの予定が3件以上」をすべて満たす行だけです。全体の遵守率のような合成値は作りません。

### 振り返り

**羅針盤** は、投下した時間と充実度を並べた面です。充実の回答が5件に満たないアクティビティは点にせず、点になるのを待っている一覧に置きます。

## 見たいアクティビティだけに絞る

サイドバー（モバイルはタブ行のボタンから開くDrawer）に、カレンダーと同じようにカテゴリーとアクティビティが並びます。数えたくない行の目のアイコンを押すと、どのタブもすぐに計算し直されます。

- カテゴリーを外すと、その中のアクティビティがまとめて外れます
- 外した状態はこの端末にだけ保存されます。新しく作ったアクティビティは自動で数えられます
- アクティビティを付けていない記録は、絞り込みの対象にならず常に数えられます

余白（記録しなかった時間）は、絞り込みでは動きません。期間の長さから記録の合計を引いた残りで、記録時間のカードに数字で添えるだけです。配分の区画にはしません。

## 数字が出ないとき

数えるに足りない回数で比率は作りません。足りなければ空欄でも0%でもなく、ダッシュで黙ります。

| 面           | 黙る条件                                |
| ------------ | --------------------------------------- |
| 差分の予定比 | 終了済みの予定が15分未満                |
| 見積もりの鏡 | 終了済みの予定が30分未満、または3件未満 |
| 羅針盤の点   | 充実の回答が5件未満                     |
| 長さの分布   | 記録が3件未満                           |

平均は出しません。中央値と件数で語ります。

## 数字から明細へ降りる

行や点を押すと、詳細パネル（モバイルはボトムシート）が開きます。

記録の合計、予定との差、1件あたりの中央値、充実度の分布、見積もりの鏡、1件の長さの分布、時間帯の分布、週別の推移、そして明細が並びます。モバイルでは週別の推移だけ出しません。

明細の行を押すと、その記録の日を1日表示で開き、その記録を選んだ状態になります。カレンダーへ降りる導線は明細の行だけが持ちます。

レポートの上では予定も記録も作れません。直すのはカレンダーの仕事です。

## 点数やstreakを使わない理由

振り返りは成績表ではありません。数字と事実だけを示し、良い・悪いの評価はしません。スコア、streak、カバー率、目標バーは作りません。催促もしません。

比べる相手は他のユーザーではなく、自分の過去の記録だけです。

## 無料プランとProプランの違い

無料プランでは、週の振り返りを指標の制限なく使えます。Proプランでは、月・年の俯瞰と、過去の自分との比較が加わります。
