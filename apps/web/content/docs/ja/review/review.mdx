# アクティビティの記録を見る

ホームのカレンダーから、特定のアクティビティの最近の記録を確認できます。アクティビティ一覧またはタイムブロックのアクティビティメニューから「詳細」を開いてください。

## 表示される内容

ユーザー設定のタイムゾーンにおける直近30日分を表示します。

- アクティビティに記録した時間の合計
- 1件あたりの記録時間の中央値
- 新しい順の記録一覧

一覧は最大200件です。さらに古い記録がある場合は、表示していない件数を案内します。予定は合計に含みません。

## 記録をカレンダーで開く

記録を選ぶと、その日をカレンダーに表示し、該当する記録を選択した状態で開きます。そこで内容を確認・編集できます。

タイムブロックの Inspector を開くとアクティビティ詳細は閉じ、アクティビティ詳細を開くと Inspector は閉じます。モバイルではシートで表示します。
