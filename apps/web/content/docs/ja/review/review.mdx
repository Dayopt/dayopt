# 振り返りを読む

振り返りは、カレンダーの右側パネルで予定と記録の差を読む機能です。独立したページはありません。カレンダーを表示したまま、点数やstreakを使わずに数字と事実だけで振り返れます。

## 振り返りを開く

カレンダー画面のツールバーから振り返りアイコンを押すと、右側にパネルが開きます。日表示・週表示・複数日表示のどれでも、表示を保ったまま開閉できます。

パネル上部で、振り返る対象をセグメントごとに絞り込めます。「すべて」を選ぶと、後述する週の振り返りが表示されます。

## 差分で見る

差分は、いま表示している期間の予定と記録を4つに分けて示します。

| 状態             | 意味                               |
| ---------------- | ---------------------------------- |
| 未記録           | 予定を立てたが、まだ記録していない |
| 予定に対する記録 | 予定どおり、またはズレて記録した   |
| 予定外の記録     | 予定していなかった時間を記録した   |

予定と記録がぴったり一致した項目（差が0）は一覧に出しません。期間全体で差が0のときは「0分」とだけ静かに表示します。

差の正負は数字と矢印アイコンで示します。成功・失敗を示す色や評価ラベルは使いません。

## 週の振り返りで見る

「すべて」を選ぶと、期間全体の振り返りが表示されます。

- **合計時間** — その期間に記録した合計時間
- **計画率** — 記録時間 ÷ 経過済み予定時間（分母15分未満は表示しない）
- **Time P/L**（予定と実際の時間の損益） — アクティビティごとに、予定していた時間と実際の時間を並べて比較
- **見積もりバイアス** — アクティビティごとに、予定と実際のズレが大きいものから並べて表示
- **スキップ** — スキップした予定の件数と合計時間
- **空白** — 予定も記録も無い時間の割合

表示期間は、いま選んでいるカレンダーの表示範囲と同じです。振り返りだけの別期間は選べません。

## 点数やstreakを使わない理由

振り返りは成績表ではありません。数字と事実だけを示し、良い・悪いの評価はしません。比べる相手は他のユーザーではなく、自分の過去の記録だけです。

## 利用期間終了後の閲覧

無料体験中と契約中に機能差はありません。利用期間終了後も、保存済みデータの週・月・年のレポートと明細を閲覧できます。
