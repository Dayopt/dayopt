# カレンダーを操作する

カレンダーはDayoptの作業画面です。予定と記録がここに並びます。このページでは、表示の切り替えかたと基本の操作をまとめます。

## ビューを切り替える

表示できる期間は3種類です。

| ビュー         | 用途                    | ショートカット |
| -------------- | ----------------------- | -------------- |
| **1日表示**    | 1日の中身を細かく見る   | `Cmd+1`        |
| **2〜7日表示** | 数日分を並べて見る      | `Cmd+3` ほか   |
| **週表示**     | 1週間の使い方を俯瞰する | —              |

ヘッダーのビュー切り替えボタンから選びます。日数は2日から7日まで指定できます。ショートカットは3日・5日・7日に割り当てています。

| ショートカット | 動作      |
| -------------- | --------- |
| `Cmd+1`        | 1日を表示 |
| `Cmd+3`        | 3日を表示 |
| `Cmd+5`        | 5日を表示 |
| `Cmd+7`        | 7日を表示 |

## 日付を移動する

| 操作           | 動作                     |
| -------------- | ------------------------ |
| `Cmd+←`        | 前の期間へ               |
| `Cmd+→`        | 次の期間へ               |
| `Cmd+T`        | 今日へ戻る               |
| 左右にスワイプ | 前後の期間へ（モバイル） |

移動する幅は、いま選んでいるビューの期間です。3日表示なら3日ずつ動きます。

## タイムブロックを作る

カレンダー上の予定と記録をまとめて「タイムブロック」と呼びます。作りかたは4つです。

| 方法          | 操作                                       |
| ------------- | ------------------------------------------ |
| **クリック**  | 空いている時間帯をクリックする             |
| **ドラッグ**  | 時間の範囲をドラッグして開始と終了を決める |
| **`C`**       | タイムブロックを作る                       |
| **`Shift+C`** | 現在時刻から15分のタイムブロックを作る     |

作成するとInspector（詳細パネル）が開きます。タイトル、日付、時間、アクティビティ、メモを編集できます。

新しく作るときの時刻は15分の区切り（0分・15分・30分・45分）に揃います。ドラッグで作る最短の長さは15分です。

予定の詳しい編集方法は [予定を立てる](/docs/plans) を参照してください。

## ドラッグで動かす

- **移動** — タイムブロックを別の時間帯へドラッグする
- **リサイズ** — 下端をドラッグして終了時間を変える

ドラッグ中に `Escape` を押すと取り消せます。

既にあるタイムブロックを動かすときも15分刻みですが、揃うのは**動かした量**で時刻そのものではありません。10時07分のタイムブロックを1コマ下へドラッグすると10時22分になります。Inspectorで入れた細かい時刻が、あとからドラッグするたびに区切りへ潰れることはありません。

リサイズは掴んだ端だけが動きます。下端を引いても開始時刻は変わりません。5分より短くはできません。

## 時刻を細かく決める

区切りに合わない時刻は、Inspectorの時間の入力欄で決めます。入力欄は1分単位で、`10:07` のように直接打てます。欄を開くと出る15分刻みの候補は、よく使う時刻への近道です。

粗い配置はカレンダー上のドラッグ、細かい調整はInspector、と使い分けます。

## タイムブロックを削除する

タイムブロックを選んで `Delete` または `Backspace` を押します。タイムブロックを右クリックしてメニューから削除することもできます。

## コピーと貼り付け

`Cmd+C` でタイムブロックをコピーし、カレンダー上の置きたい位置で `Cmd+V` を押します。タイトル、長さ、アクティビティが引き継がれます。

## 表示を調整する

ビュー設定から、カレンダーの見えかたを変えられます。

| 設定       | 内容                                     |
| ---------- | ---------------------------------------- |
| 週末を表示 | 土日を表示するかどうか（`Cmd+W` で切替） |
| 週数を表示 | 週番号を左端に表示する                   |
| 密度       | コンパクト / 標準 / ゆったり の3段階     |

密度を変えると1時間あたりの高さが変わります。予定が多い日はコンパクト、細かく時間を刻む日はゆったりが使いやすいです。

## タイムブロックを検索する

`Cmd+K` で検索を開きます。タイトルからタイムブロックを探して、その日付へ移動できます。

## キーボードショートカット

`Shift+?` を押すと、いま使えるショートカットの一覧が開きます。

| ショートカット      | 動作                           |
| ------------------- | ------------------------------ |
| `Shift+?`           | ショートカット一覧を開く       |
| `Cmd+←` / `Cmd+→`   | 前 / 次の期間へ移動            |
| `Cmd+T`             | 今日へ移動                     |
| `Cmd+1` `3` `5` `7` | 1 / 3 / 5 / 7日を表示          |
| `Cmd+W`             | 週末の表示を切り替え           |
| `Cmd+K`             | タイムブロックを検索           |
| `C`                 | タイムブロックを作る           |
| `Shift+C`           | 現在時刻にタイムブロックを作る |
| `Cmd+C` / `Cmd+V`   | コピー / 貼り付け              |
| `Delete`            | 選択中のタイムブロックを削除   |
| `Escape`            | Inspectorを閉じる              |

WindowsとLinuxでは `Cmd` を `Ctrl` に読み替えてください。
