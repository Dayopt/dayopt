# Calendar

PlanとRecordを時間gridに描画するcomponent群。Storybookではviewごとの密度、2lane表現、drag state、empty stateを確認する。

## Visual contract

| View        | 確認する状態                                         |
| ----------- | ---------------------------------------------------- |
| Day         | 1日grid、Plan / Record lane、current time            |
| Week        | 7日密度、weekend、複数日の差分marker                 |
| Multi-Day   | 2〜7日の可変column                                   |
| Interaction | selection、drag preview、context menu、inline create |

- Planはoutline / 淡色、Recordは塗りを基本にする
- Review / Diff panelのcomponentとStoryはReview featureが所有する
- Calendar Storyはpanel内部やDB data flowを説明しない

| ビュー        | 説明                   | コンポーネント |
| ------------- | ---------------------- | -------------- |
| **Day**       | 1日のタイムグリッド    | `DayView`      |
| **Week**      | 7日間のタイムグリッド  | `WeekView`     |
| **Multi-Day** | 2〜7日間のカスタム表示 | `MultiDayView` |

ビュー切替は `ViewSwitcherList` コンポーネントで行い、`CalendarNavigationContext` で状態管理。
Review / Diff は view ではなく Calendar の単一 panel slot に表示する。Storybook 上の panel 表示は `Product/Features/Review` が所有し、Calendar は時間軸表示だけを扱う。

## 状態管理

### Zustand Stores

| Store                    | 用途                                 | persist |
| ------------------------ | ------------------------------------ | ------- |
| `useCalendarFilterStore` | アクティビティのフィルター           | Yes     |
| `useCalendarDragStore`   | ドラッグ元・ゴースト・プレビュー時間 | No      |
| `useCalendarScrollStore` | スクロール位置同期                   | No      |

### Context

| Context                     | 用途                                    |
| --------------------------- | --------------------------------------- |
| `CalendarNavigationContext` | 日付・ビュー・panel・ナビゲーション操作 |
| `CalendarGridProvider`      | グリッド計算の共有                      |

## ドラッグ & ドロップ

- **技術**: native pointer events（`onPointerDown` 起点の自前実装）。外部 DnD ライブラリは
  サイドバーの並べ替え廃止に伴い依存ごと撤去済み（#2162）
- **対象**: カレンダーグリッド上のタイムブロックの移動・リサイズ
- **状態**: `useCalendarDragStore`（ドラッグ元・ゴースト・プレビュー時間）
- **機能**: ドラッグプレビュー、時間計算、モバイルハプティクス

サイドバーのアクティビティは並べ替えできない（名前順に固定）。カテゴリーの
付け替えは行メニューの「カテゴリーを変更」で行う。

## フィルター

| フィルター         | 説明                                       |
| ------------------ | ------------------------------------------ |
| アクティビティ別   | アクティビティごとの表示切替               |
| アクティビティなし | アクティビティ未設定のブロックの表示トグル |

`useCalendarFilterStore` で管理、localStorage に永続化。

## データ同期

`refetchOnWindowFocus`（TanStack Query）でタブ切り替え時にデータを自動再取得。

---

## DB テーブル

| テーブル     | 用途                                                                    |
| ------------ | ----------------------------------------------------------------------- |
| `plans`      | 計画（タイトル、時間、`activity_id` 等）                                |
| `records`    | 実際に使った時間（予定とは独立）                                        |
| `activities` | Plan / Record の分類単位（`plans.activity_id` / `records.activity_id`） |
| `categories` | アクティビティの所属先。色・アイコンを持つのはこちら                    |

---

## キーボード操作

- ビュー切替、日付ナビゲーション、プラン選択
- 選択中の Plan / Record をコピーし、同じ種別の独立した Timeblock として貼り付け
- 週末トグルショートカット
- Escape でキャンセル
