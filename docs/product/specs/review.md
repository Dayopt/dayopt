# Review（旧画面仕様）

2026-10-05 に独立した `/report` 画面と `features/review` を削除したため、この仕様は superseded。現行のホームと明示的なアクティビティ詳細は [Calendar仕様](./calendar.md) を参照する。

廃止対象は週・月・年の3タブ、全体ダッシュボード、配分、前期間比較、分布、推移、予定との差、Review 専用の内部 API である。公開 MCP の `review.get` 契約、Plan / Record の保存データ、作成時の見積もり支援は別契約として維持する。

アクティビティ詳細はカレンダーから明示的に開き、直近30日の記録時間・1件あたりの中央値・記録一覧を表示する。これは全体レポートの後継ではなく、特定のアクティビティの記録を確認するための補助面である。
