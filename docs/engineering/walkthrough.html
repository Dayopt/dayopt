Dayopt 経路ウォークスルー

まず画面マップで画面どうしの移り方を見て、操作を 1 つ選び、どのサービスのどの処理を通るかを図で辿る。各段の右には利用者の画面の模型が出る。▶ で依頼が流れ、段を押すと中身とコードが出る。「⚡ ここで失敗させる」を押すと、どこで途切れ、何が画面へ戻り、データ・再試行・痕跡がどうなり、どこから確認するかが出る。目的は暗記ではなく、変更の影響先と障害時の初手を自分で引けるようにすること。

正本はコードと既存の運用文書。ここは入口にすぎない。リンクは GitHub の main を指す。記述がコードとずれていたら、この HTML の walkthrough-data を直す（pnpm docs:check が参照先の存在だけは検査する）。
