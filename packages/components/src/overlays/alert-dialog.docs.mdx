# AlertDialog

重要なアクションの確認ダイアログ。削除、ログアウト、不可逆操作で使用。

**オーバーレイクリックでは閉じない**。インストール済み Radix の既定では Escape は dismiss を要求するが、呼出側が `onEscapeKeyDown` で `preventDefault()` した場合や、controlled `open` を更新しない場合は閉じない。
この [wrapper](alert-dialog.tsx) は Escape を一律に禁止せず、Content の props を Radix へ渡す。Cancel / Action の明示的な選択を用意し、閉じ方は呼出側の `open` / `onOpenChange` と合わせて確認する。

## Dialog vs AlertDialog

|                      | Dialog                             | AlertDialog                        |
| -------------------- | ---------------------------------- | ---------------------------------- |
| ESCで閉じる          | 既定は ○（props / state で制御可） | 既定は ○（props / state で制御可） |
| オーバーレイクリック | ○                                  | ✕                                  |
| 用途                 | 一般的なモーダル                   | 重要な確認                         |

## コンポーネント構成

| コンポーネント           | 役割                                  |
| ------------------------ | ------------------------------------- |
| `AlertDialog`            | ルートコンテナ（状態管理）            |
| `AlertDialogTrigger`     | 開くトリガー（asChild対応）           |
| `AlertDialogContent`     | コンテンツ（中央配置、rounded-2xl）   |
| `AlertDialogHeader`      | ヘッダー（Title + Description）       |
| `AlertDialogTitle`       | タイトル（text-lg font-medium）       |
| `AlertDialogDescription` | 説明（asChildでカスタムコンテンツ可） |
| `AlertDialogFooter`      | フッター（Cancel + Action）           |
| `AlertDialogCancel`      | キャンセルボタン（variant: outline）  |
| `AlertDialogAction`      | 実行ボタン（variant: default）        |
