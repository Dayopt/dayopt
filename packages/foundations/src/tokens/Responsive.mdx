# Responsive

Material Design 3 Window Size Classes に基づくレスポンシブデザインガイド。

---

## ブレークポイント（Tailwind v4 デフォルト）

| Prefix | Min Width | M3 対応             | 用途             |
| ------ | --------- | ------------------- | ---------------- |
| `sm:`  | 640px     | Compact/Medium 境界 | タブレット縦     |
| `md:`  | 768px     | Medium              | タブレット縦     |
| `lg:`  | 1024px    | Expanded            | デスクトップ     |
| `xl:`  | 1280px    | Large               | ワイドスクリーン |
| `2xl:` | 1536px    | Extra-large         | 超ワイド         |

## レイアウト切替アーキテクチャ

`MEDIA_QUERIES.mobile`（max-width: 767px）で MobileLayout / DesktopLayout を二分岐する。

| 画面幅  | レイアウト    | ナビゲーション                            | サイドバー                    |
| ------- | ------------- | ----------------------------------------- | ----------------------------- |
| < 768px | MobileLayout  | Header account icon / Calendar tag footer | なし                          |
| ≥ 768px | DesktopLayout | Sidebar                                   | w-64（256px）、折りたたみ w-0 |

### 判定フック

| フック          | 判定基準                                  | 用途                     |
| --------------- | ----------------------------------------- | ------------------------ |
| `useMediaQuery` | `MEDIA_QUERIES.mobile` (max-width: 767px) | レイアウト切替           |
| `useIsMobile`   | 画面幅 < 768px **かつ** タッチデバイス    | UI振る舞い（タップ操作） |

```tsx
// レイアウト切替（base-layout-content.tsx）
const isMobile = useMediaQuery(MEDIA_QUERIES.mobile);

{
  isMobile ? <MobileLayout>{children}</MobileLayout> : <DesktopLayout>{children}</DesktopLayout>;
}
```

### Mobile Footer

モバイルの固定フッターは Calendar のタグクイック作成だけに使う。ページナビゲーションは持たず、アカウント導線は右上の account icon に置く。

| プロパティ   | 値                                  |
| ------------ | ----------------------------------- |
| 高さ         | h-14（56px）                        |
| z-index      | z-bottom-tab（40）                  |
| セーフエリア | pb-safe（iOS ホームインジケーター） |
| 内容         | TagChipRow（Calendar のみ）         |

Calendar のメインコンテンツには `pb-16`（64px）でタグフッター分の余白を確保。Calendar 以外の mobile page は固定フッターを持たない。

### デスクトップサイドバー

| プロパティ | 値                               |
| ---------- | -------------------------------- |
| 幅（開）   | w-64（256px）                    |
| 幅（閉）   | w-0（collapse、transition-all）  |
| 背景       | bg-container（Sunken elevation） |

## カレンダー/タイムラインのレスポンシブ

### ビュー表示ルール

ユーザーが選択できるビューと、renderer が受け取ったビューを描く時のフォールバックは区別する。

| 条件         | ナビゲーション / 描画の責務                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------------- |
| モバイル     | Navigation は Day のみを許可する。Renderer の Week 分岐も Day に収束させる                                    |
| タブレット   | Week の描画は狭い列を避けるため Multi-Day にフォールバックする。明示的に選んだ Multi-Day は指定列数を維持する |
| デスクトップ | 選択された Day / Week / Multi-Day を描画する                                                                  |

選択可否と URL の補正は [CalendarNavigationContext](../../../../apps/product/src/features/calendar/hooks/navigation/CalendarNavigationContext.tsx)、列数と描画フォールバックは [CalendarViewRenderer](../../../../apps/product/src/features/calendar/components/controller/components/CalendarViewRenderer.tsx) を正本とする。Renderer のモバイル Multi-Day 制限は、ナビゲーションがそのビューを提供するという意味ではない。

製品として提供する表示範囲と操作の意味は [Calendar仕様](../../../../docs/product/specs/calendar.md) を確認し、実装との相違は別途照合する。ここには列数定数や分岐コードの写しを置かない。

### グリッド密度（時間あたり高さ）

時間グリッドは常にコンテナ実測高（viewport高からヘッダー等を除いた高さ）へ 24h をフィットさせ、密度プリセットはそのフィットに対する倍率として表現する（`DENSITY_FACTOR`、`src/features/calendar/lib/constants.ts`）。

| 密度     | フィットに対する倍率 | 挙動                                           |
| -------- | -------------------- | ---------------------------------------------- |
| compact  | 1.0                  | 24h がコンテナ高に正確に一致（スクロールなし） |
| default  | 1.5                  | フィットの1.5倍。意図的にスクロールを許容      |
| spacious | 2.0                  | フィットの2倍。意図的にスクロールを許容        |

`hourHeight = Math.max(MIN_LEGIBLE_HOUR_HEIGHT, Math.floor((containerHeight / 24) * DENSITY_FACTOR[density]))`

## タッチターゲット

Material Design 3 / Apple HIG アクセシビリティ準拠。

| サイズ   | Tailwind    | ピクセル | 用途                |
| -------- | ----------- | -------- | ------------------- |
| minimum  | `h-11 w-11` | 44px     | WCAG 2.5.5 最小     |
| standard | `h-12 w-12` | 48px     | M3 推奨（標準）     |
| large    | `h-14 w-14` | 56px     | FAB、重要アクション |

### レスポンシブタッチターゲット

```tsx
// ✅ モバイルで大きく、デスクトップで通常サイズ
<Button className="h-12 w-12 sm:h-10 sm:w-10">
  <Icon className="size-6 sm:size-5" />
</Button>
```

### ルール

- ✅ 最小タッチターゲット 44x44px
- ✅ 推奨サイズ 48x48px
- ✅ モバイルで常時表示、デスクトップでホバー表示
- ✗ 24px 以下のタッチターゲット
- ✗ ホバーのみでアクセスできる UI（モバイル不可）

## ホバー依存 UI のモバイル対応

ホバーで表示される UI はモバイルで常時表示にする。

```tsx
// ✅ モバイルで常時表示、デスクトップでホバー時のみ
<button className="opacity-100 sm:opacity-0 sm:group-hover:opacity-100">
  <TrashIcon />
</button>

// ❌ ホバーのみ（モバイルでアクセス不可）
<button className="opacity-0 group-hover:opacity-100">
```

## 固定幅のレスポンシブ化

```tsx
// ✅ Tailwind 標準クラス使用
<div className="w-72 sm:w-80">         // 288px → 320px
<div className="w-full max-w-sm sm:w-96">  // 全幅 → 384px

// ❌ 任意値の多用は避ける
<div className="w-[25rem]">            // → w-96
<div className="max-w-[85vw]">         // → max-w-72
```

## ブレークポイント使用状況

コードベースでの Tailwind レスポンシブプレフィックス使用頻度。

| Prefix | 出現回数 | ファイル数 | 主なパターン                             |
| ------ | -------- | ---------- | ---------------------------------------- |
| `md:`  | 140      | 59         | grid-cols-\*(57), p-\*(18), hidden/block |
| `sm:`  | 82       | 33         | grid-cols-\*(18), space-y-\*(10), w-\*   |
| `lg:`  | 34       | 19         | grid-cols-\*(12), p-\*(3)                |
| `xl:`  | 7        | 5          | まれに使用                               |
| `2xl:` | 1        | 1          | ほぼ未使用                               |

**設計方針**: `md:` を主要ブレークポイントとし、レイアウト切替に使用。`sm:` はコンポーネント単位の微調整。`lg:` 以上は必要な場合のみ。
